# Current Refund Policy (v2.0 — Active)

## 1. Eligibility Window [policy-window]
Customers may request a self-service refund within **30 calendar days** of delivery. Orders older than 30 days are ineligible for automatic refund.

## 2. Automatic Approval Cap [policy-cap]
Support agents may issue instant refunds up to **$500 USD** per order. Any refund above $500 USD requires a supervisor escalation code (`SUP-APPROVED`) and cannot be issued automatically.

## 3. Digital Software Licenses [policy-digital-licenses]
Downloaded digital software licenses, activation keys, and cloud subscription seats that have already been redeemed or activated are non-refundable after activation, except within 14 calendar days if the license key was never activated.

## 4. VIP Enterprise Exceptions & Restocking Fees [policy-vip-restocking]
Standard hardware returns opened after delivery incur a 10% restocking fee unless defective. VIP Enterprise tier customers receive a waived 0% restocking fee and priority carrier return labels on all eligible hardware returns.

## 5. Tenant Isolation [policy-tenant]
Agents and tools must only access or refund orders belonging to the caller's authenticated `tenantId`. Cross-tenant order access is strictly forbidden.

## 6. Citation Requirement [policy-citation]
Every customer-facing refund decision must cite the active policy section as `[policy]`.
